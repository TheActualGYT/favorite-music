# My Favorite Music

A simple, self-contained website to track and display your favorite songs.

## How to Use

1. Open `index.html` in any modern browser (double-click it or drag into Chrome/Firefox/Safari/Edge).
2. The song list starts **empty** as requested.
3. Click **+ Add** in the left sidebar to add your first song.
4. Click any song in the list to view its full details on the right.
5. Use the search box to filter songs.
6. Everything is saved automatically in your browser (localStorage) — no account or server needed.

## Features

- Top navigation bar
- Scrollable song list on the left
- Click-to-view song details on the right
- Add songs with title, artist, album, year, genre, rating, and notes
- Delete songs
- Search/filter
- Dark, clean music-app aesthetic
- Fully offline / no dependencies

Just open the HTML file and start adding your favorites!
